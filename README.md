# Escape Game 
### Mathéo Rambatomanga & Jules Heyndels

Pour lancer le jeu, il suffit de lancer ` docker compose up -d ` dans le terminal du dossier parent.
Ensuite, rendez vous sur [localhost:1234](http://localhost:1234/) et profitez du jeu !
